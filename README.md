# COSMADEDZ — PWA تدريبية لصناعة مستحضرات التجميل والعناية بالجسم

تطبيق ويب تقدمي (PWA) عربي **RTL**، يعمل دون اتصال بعد التحميل الأول، وموجّه للتكوين العملي في:
- أساسيات التجميل والجلد
- المواد الأولية مع **تصنيف وظيفي** (منطق مستوحى من UL Prospector Personal Care)
- الوصفات (نسب 100% + حاسبة دفعة + خطوات)
- طرق التصنيع ونقاط التحكم الحرجة (CCP)
- الجودة والسلامة (قائمة GMP، اختبارات أساسية)
- اختبارات تقييم وشهادة إتمام
- معجم مصطلحات ومختبر حاسبات (تحويل نسبة/غرام، HLB تقريبي، تصبّن تقريبي تعليمي)

> المحتوى تعليمي عام ولا يغني عن اختبارات الاستقرار/السلامة أو الالتزام التنظيمي المحلي قبل التسويق.

**الحقوق محفوظة للمهندس: حاج اسماعيل ابراهيم** — مهندس مراقبة النوعية والبيوكيمياء، غرداية الجزائر — هاتف: 0549659691

## التشغيل محلياً

لا توجد أدوات بناء (بدون Node). شغّل خادم المصادقة المرفق (Python 3 القياسي فقط)، فهو يقدّم التطبيق وواجهة الدخول معاً:

```bash
cd cosmadedz-pwa
python server/server.py
```

ثم افتح: `http://127.0.0.1:8123/`

عند أول تشغيل تُنشأ قاعدة البيانات وتُولّد كلمة مرور المسؤول في `server/data/admin-password.txt`. راجع [`server/README.md`](./server/README.md) للإعداد والبريد (SMTP) وHTTPS.

> يمكن أيضاً تقديم الملفات الثابتة فقط عبر `python -m http.server 8765` للتصفح دون تسجيل دخول، لكن طلب التفعيل/لوحة الإدارة يحتاجان خادم المصادقة.

> ملاحظة: Service Worker/PWA يعمل بشكل صحيح عبر `http/https` (أو `localhost`)، وليس عبر فتح `index.html` مباشرة كملف. للنشر على الإنترنت يلزم HTTPS.

## الحساب والتفعيل

- يقدّم المستخدم طلب دخول (الاسم، الهاتف، البريد) من صفحة الدخول.
- المسؤول يدخل من `#/admin` مباشرة: لا يظهر رابط اللوحة ولا بريد المسؤول ولا كلمة المرور في واجهة المستخدم.
- يوافق المسؤول على الطلب ويصدر كوداً من 6 أرقام صالحاً 15 دقيقة.
- بعد الموافقة يُرسل الكود تلقائياً بالبريد إن كانت SMTP مهيأة؛ وإلا يُعرض في لوحة الإدارة لنسخه وتسليمه (هاتف/واتساب).
- بعد **8 محاولات فاشلة** يُلغى الكود ويجب إصدار كود جديد من لوحة الإدارة.
- الردود عامة عمداً (لا تكشف إن كان البريد مسجلاً أو مفعّلاً) لمنع تعداد الحسابات.
- بعد التفعيل تُحفظ جلسة Bearer في `localStorage` (مفتاح `cosd_v1_session`).
- رابط «لوحة الإدارة» يظهر في القائمة الجانبية والشريط السفلي للمسؤول فقط، ويُخفى تماماً عن المستخدمين.
- صفحة «القائمة» (`#/menu`) تجمع كل الأقسام والحساب وتسجيل الخروج.
- عند انقطاع الخادم تبقى الجلسة المحلية صالحة للدراسة دون اتصال؛ الجلسة تُمسح فقط عند 401/403.

## اللغات (عربي / إنجليزي / فرنسي)

- زر اللغة في الشريط العلوي يبدّل بين `العربية` و`English` و`Français` فوراً دون إعادة تحميل.
- تبقى العربية هي اللغة الافتراضية والمرجعية (`dir="rtl"`)، بينما الإنجليزية والفرنسية تعملان باتجاه `ltr`.
- الترجمة تخص **واجهة التطبيق فقط**: العناوين، التسميات، الأزرار، الرسائل، وحقول الإدخال. أما نصوص الدروس والوصفات والمواد الأولية والاختبارات فتبقى بالعربية كما هي المصدر المعتمد، مع إظهار العنوان الفرعي بالفرنسية/الإنجليزية إن توفّر في البيانات.
- تُحفظ اللغة في `localStorage` بالمفتاح `cosd_v1_lang` وتُطبّق عند كل تشغيل.
- لإضافة أو تصحيح ترجمة: عدّل `js/i18n-data.js` (المفتاح هو النص العربي كما يظهر حرفياً). النصوص المركّبة (أرقام، عدّادات، شرائح) تُعالج عبر `COSD_I18N_RULES` في نفس الملف.
- عند إضافة واجهة جديدة استخدم السلاسل العربية نفسها في `app.js`/`app-pages.js`؛ المحرّك يترجمها تلقائياً عند العرض.
- بعد تعديل أي ملف ترجمة ارفع رقم `VERSION` في `sw.js` لتفادي خدمة نسخة قديمة من الكاش.

## الأمان

- الخادم يرسل ترويسات أمان صارمة (CSP، منع التأطير، nosniff، Referrer-Policy، Permissions-Policy، COOP/CORP، وHSTS مع TLS).
- واجهات API تقبل JSON فقط بحد أقصى 64KB، مع حدود محاولات لكل IP/بريد وحد عام.
- الملفات الثابتة محمية من اجتياز المسارات وكشف ملفات الخادم/قاعدة البيانات/النسخ الاحتياطية.
- أكواد التفعيل والجلسات تُخزَّن مجزّأة (HMAC / SHA-256) وليست نصاً.
- يمكن تشغيل المسؤول بكلمة مرور PBKDF2-SHA256 بدل النص العادي: `python server/server.py --hash-password`.
- HTTPS مباشر اختياري عبر `--tls-cert`/`--tls-key`، أو ضعه خلف وكيل HTTPS. راجع [`server/README.md`](./server/README.md).

## البيانات

- كل ملف بيانات يعرّف متغيراً عاماً واحداً أو أكثر على `window` (مثل `COSMA_RECIPES`) بصيغة سكربت عادي (بدون ESM).
- عقد البيانات موثّق في [`DATA-SCHEMA.md`](./DATA-SCHEMA.md).
- التقدم/النتائج/المفضلة/قائمة GMP/الاسم تُحفظ محلياً في `localStorage` ببادئة `cosd_v1_`.
- طلبات الدخول والجلسات تُحفظ في خادم المصادقة (`server/data/app.db`)، وليس في المتصفح.
